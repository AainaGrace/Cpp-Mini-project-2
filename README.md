# Student Mark Analyzer (C++)

A simple Object-Oriented C++ program demonstrating encapsulation, constructors, getters/setters with validation, and object arrays using a `Student` class.

## Features

- **Encapsulation & Validation:** Restricts direct access to `rollNo`, `name`, and `marks`, ensuring marks stay between `0` and `100`.
- **Student Display:** Prints formatted student details (Roll Number, Name, and Marks).
- **Pass/Fail Evaluation:** Evaluates each student's marks against a passing threshold of `40` via the `Result()` function.

## Prerequisites

You need a C++ compiler installed on your system, such as **GCC (`g++`)** or **Clang**.
